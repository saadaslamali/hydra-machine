Hydra machine is a physical arduino instrument that lets me live code with Hydra without having to type out functions.
Building on the interface by Aaryan (https://github.com/caizoryan/hydra-interface)
The goal is to this to only generate correct/working hydra code, so that I can do stuff very quickly 
and also to force myself to do hydra in a way that is different from what im used to
the ultimate hydra machine

Hydra machine is a physical arduino instrument that lets me live code with Hydra without having to type out individual letters.
Building on the interface by Aaryan (https://github.com/caizoryan/hydra-interface). I've been making it so that it can only generate working hydra code.

The ultimate hydra machine...
